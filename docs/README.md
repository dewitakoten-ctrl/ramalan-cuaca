# Weather Dashboard

A simple static weather dashboard built with HTML, CSS, and JavaScript.

## Features
- Search by city name
- Display current weather
- Display 5-day midday forecast
- Responsive layout for desktop and mobile

## Setup
1. Get a free API key from OpenWeatherMap: https://openweathermap.org/api
2. Open `weather-dashboard/app.js`
3. Replace `YOUR_OPENWEATHERMAP_API_KEY` with your API key

## Run locally
Open `weather-dashboard/index.html` in your browser.

## Deploy to GitHub Pages
1. Create a GitHub repository and push this folder.
2. Enable GitHub Pages in repository settings.
3. Set the publish branch to `main` or `gh-pages` and folder to `/`.
4. Visit the published URL.
