# Weather Dashboard - Proyek Aplikasi Cuaca

Aplikasi web sederhana untuk menampilkan informasi cuaca saat ini dan ramalan cuaca 5 hari ke depan menggunakan OpenWeatherMap API.

## Fitur Utama (GONG)
* Pencarian Cuaca Berdasarkan Nama Kota.
* Eksekusi Asynchronous menggunakan `Promise.all` (Fetch API).
* Responsif terhadap klik tombol dan tombol *Enter* pada keyboard.
