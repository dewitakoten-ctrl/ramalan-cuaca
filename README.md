# ramalan-cuaca

A simple project containing two web apps:

## Apps included

### 1. Simple To-Do List App
- Add tasks
- Edit tasks inline
- Mark tasks complete
- Remove tasks
- Persist tasks in `localStorage`

Open `index.html` in the project root to run the to-do list app.

### 2. Weather Dashboard
- Search weather by city name
- Display current conditions
- Display a 5-day forecast

Open `weather-dashboard/index.html` to run the weather dashboard.

## Run locally
Open `index.html` or `weather-dashboard/index.html` in your browser.

## Deploy to GitHub Pages
1. Push the repository to GitHub.
2. Enable GitHub Pages in repository settings.
3. Set the publish branch to `main` and folder to `/`.
4. Visit the published site URL.
